Air Jordan 5 Retro — Product Page

A responsive product page for the Nike Air Jordan 5 Retro, built with HTML, CSS, and vanilla JavaScript.

Features

- Interactive product image gallery
- Product quantity selector with increment and decrement buttons
- Responsive layout for desktop and mobile screens
- Custom typography using local font files
- Product pricing and discount display
- Minimal design with CSS Flexbox and Grid

Built With

- HTML5
- CSS3
- JavaScript (Vanilla)
- Font Awesome

Getting Started

1. Clone this repository.
2. Open the project folder.
3. Open "index.html" in your browser.

No build tools or package installation are required.

Notes

This project focuses on the product page UI and basic interactions. The Add to Cart button does not yet implement shopping cart functionality.
